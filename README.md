# پروژه رزومه تعاملی با FastAPI

این پروژه یک **رزومه آنلاین تعاملی** با فرم درخواست پروژه و صفحه مدیریت ادمین است. پروژه با **HTML, CSS و FastAPI** ساخته شده و شامل امکانات زیر است:

---

## ویژگی‌ها

### 1. صفحه رزومه
- نمایش اطلاعات رزومه و مهارت‌ها.
- فرم درخواست پروژه با فیلدهای:
  - نام و نام خانوادگی
  - ایمیل
  - نوع پروژه (وب / دیتا / نرم‌افزار)
  - توضیح کوتاه پروژه
- ارسال درخواست‌ها به سرور با **API FastAPI**.

### 2. صفحه ادمین
- احراز هویت ساده با یوزرنیم و پسورد:
  - یوزر: `admin`
  - پسورد: `admin123`
- مشاهده تمام درخواست‌های ارسال شده.
- امکان **مدیریت درخواست‌ها**:
  - Accept / Delete
- طراحی زیبا با CSS اختصاصی (`admin.css`).
- ستون‌ها:
  - ID
  - Name
  - Email
  - Project Type
  - Project Description
  - Status
  - Action

### 4. تعداد کاربران آنلاین (وب‌سوکت)
- نمایش تعداد کاربران آنلاین در صفحه رزومه.
- هر بار که کاربری وارد می‌شود، عدد آنلاین‌ها بروزرسانی می‌شود.

1. کلون کردن پروژه (یا انتقال پوشه پروژه به سیستم لوکال).
2. ایجاد و فعال کردن محیط مجازی:
```bash
python -m venv venv
venv\Scripts\activate   # ویندوز
source venv/bin/activate # لینوکس / مک
نصب پکیج‌ها:


pip install fastapi uvicorn sqlalchemy jinja2 pydantic
اجرای سرور:

uvicorn backend.main:app --reload
